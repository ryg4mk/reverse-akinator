# 逆アキネーター

質問するのは、あなた。ゲームがひとつお題を選び、プレイヤーには現在の回答に応じて最大4つの質問候補が表示され、その中から1つずつ質問を選択。ゲーム側は「はい」「いいえ」「どちらともいえません」で答えます。分かったらテキスト入力で回答し、正解判定します。

## v1.4 の変更点（やさしいモードを改善）
- 全160種類のお題に、名前そのものを質問文に使わない、具体的で連想しやすい「特徴質問」を各1つ追加。質問は合計306種類。
- 「やさしい」モードは大分類→身近な特徴→そのお題らしい質問の順に進む。
- 原則5問目以降に、そのお題の特徴を確認できる質問と、似たお題の特徴質問を並べる。プレイヤーは選んだ質問の答え（はい／いいえ）をもとに判断できる。
- 必ず正解側の特徴質問が候補に入るが、どの位置に表示されるかは固定ではない。質問で答えるルールはこれまでと同じ。
- 「ふつう」「むずかしい」も後半で特徴質問を利用できる（保証付きのヒントはやさしい限定）。
- 1画面のゲームUI、回答入力、履歴、スコア、今日の1問は維持。

## 遊び方

1. 難易度（やさしい・ふつう・むずかしい）とランダム／今日の1問を選んでゲーム開始。
2. 序盤の基本分類から表示された最大4つの質問を選択。質問後は、その回答で絞り込んだ新しい質問に自動で切り替わります。『ほかの質問を見る』も選べます。
3. 質問の回答を参考に、いつでも「答えを入力」から名前を入力。
4. 正解すると質問数・ミス数に応じてスコアが表示されます。不正解でも再挑戦できます。

ひらがな、カタカナ、漢字、代表的な別名のいくつかに対応しています。正解判定は**ゲーム内のお題データとの照合**であり、AIサービスに通信する仕様ではありません。

## GitHub Pages で公開

**リポジトリの直下に、ZIP 内のファイルをすべて置くこと。** ZIP 自体や `reverse-akinator` フォルダーをアップロードしても、リポジトリの直下に `index.html` がないと正常に公開されません。

1. GitHub で新しい公開リポジトリ（例：`reverse-akinator`）を作成。
2. このZIPを展開し、`index.html` `style.css` `data.js` `app.js` `favicon.svg` を**まとめてリポジトリ直下に**アップロードしてコミット。`README.md` も任意でアップロードできます。
3. **Settings → Pages → Build and deployment** の **Source** を `Deploy from a branch` に設定。
4. **Branch** を `main`、**Folder** を `/(root)` にして **Save**。
5. 公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` の形式です。

※プロジェクトサイト（サブディレクトリURL）対応です。すべて相対パスで読み込みます。

## カスタマイズ

- `data.js`: `add(...)` でお題を増減できます。質問は `questions` 配列に登録します。質問候補はお題の属性をもとに絞り込み、区別できる候補だけを動的に提示します。
- `style.css`: 配色・レイアウトを調整できます。
- `app.js`: 出題方法・正解判定・スコア計算・画面を制御します。
- **オフライン動作**: 外部CDN、API、インターネット通信、ビルド作業は不要です。
- **セーブ**: 自己ベスト・連続正解・最近出たお題・音声設定などはブラウザの `localStorage` に保存されます。端末を変えても共有されません。
- **今日の1問**: 日本時間の日付と難易度でお題を決めます。難易度が同じなら同じ日の同じお題が出ます。サーバーランキング機能はありません。

## ご注意

収録した単語への回答は、個別の属性データに基づいた固定判定です。日常語には曖昧な場合があるため、「イメージですか？」という質問をいくつか採用しています。必要に応じて `data.js` で回答属性を調整してください。イラストはOS標準の絵文字を使用しており、端末により見た目が異なります。
